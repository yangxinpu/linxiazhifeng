# 00 · API 简介与全局约定

## Base URL

```
/api
```

所有接口路径均以前缀 `/api` 开头。前端通过 Axios `baseURL` 配置自动附加，调用时只需传入相对路径，如 `get('/quotes/latest')`。

## 统一响应格式

所有接口的 HTTP 响应体都必须遵守以下 JSON 结构：

```typescript
interface ApiResponse<T> {
  code: number    // 业务状态码，0 表示成功，非 0 表示业务异常
  message: string // 业务提示信息
  data: T         // 业务数据，成功时返回具体类型，失败时通常为 null
}
```

## 分页响应

列表类接口使用分页结构：

```typescript
interface PaginatedResponse<T> {
  list: T[]       // 当前页的数据列表
  total: number   // 符合条件的总记录数
  page: number    // 当前页码（从 1 开始）
  pageSize: number // 每页大小
}
```

## 请求参数传递规则

| 方法 | 参数位置 | 说明 |
|------|---------|------|
| `GET` | Query String | 所有参数拼接到 URL 上，如 `?page=1&pageSize=10` |
| `POST` | Request Body (JSON) | 请求体为 JSON 对象 |
| `PATCH` | Request Body (JSON) | 请求体为 JSON 对象 |
| `DELETE` | Path Variable | 通过 URL 路径传参，如 `/quotes/:id` |

多值查询参数同时支持两种形式：
- 重复键：`?form=poetry&form=aphorism`
- 逗号分隔：`?form=poetry,aphorism`

## 鉴权

前端通过 `localStorage.getItem('token')` 读取 Token，并在请求拦截器中自动附加 `Authorization: Bearer <token>` 头。当前 Mock 阶段所有接口无实际鉴权校验。

## 业务状态码

业务码由前后端共同约定。`code === 0` 表示成功，非 0 表示业务异常。

### 成功码

| code | message | 说明 |
|------|---------|------|
| `0` | 操作成功 | 通用成功码，所有成功响应的 `code` 字段 |

### 认证相关（1xxxx）

| code | message | 说明 |
|------|---------|------|
| `10001` | 账号不存在 | 登录时查询不到该账号 |
| `10002` | 密码错误 | 登录时密码不匹配 |
| `10003` | 账号已被禁用 | 账号状态异常，需联系管理员 |

### 参数校验（3xxxx）

| code | message | 说明 |
|------|---------|------|
| `30001` | 参数校验失败 | 必填参数缺失、类型错误或值超出范围 |
| `30002` | 数据重复，请勿重复提交 | 幂等校验失败（如点赞已存在时再次请求） |

### 文件上传（4xxxx）

| code | message | 说明 |
|------|---------|------|
| `40001` | 文件上传大小超出限制 | 文件大小超过后端配置限制 |
| `40002` | 文件格式不支持 | 文件 MIME 类型不在允许列表内 |

### 资源相关（404xx）

| code | message | 说明 |
|------|---------|------|
| `40400` | 请求资源不存在 | 目标资源（名言/文章/书本等）不存在或已删除 |

## HTTP 状态码

| HTTP 状态码 | 含义 | 前端友好提示 |
|-------------|------|-------------|
| `200` | 请求成功 | — |
| `400` | 请求参数错误 | "请求参数错误" |
| `401` | 未认证 / Token 失效 | "登录已过期，请重新登录" |
| `403` | 无权限 | "无权限访问该资源" |
| `404` | 资源不存在 | "请求的资源不存在" |
| `405` | 方法不允许 | "请求方法不允许" |
| `429` | 限流 | "请求过于频繁，请稍后再试" |
| `500` | 服务器内部错误 | "服务器内部错误" |
| `502` | 网关错误 | "网关错误" |
| `503` | 服务不可用 | "服务暂时不可用" |
| `504` | 网关超时 | "网关超时" |

## 错误处理约定

前端响应拦截器（`http-client.ts`）按以下优先级处理异常：

1. **HTTP 层异常**：请求未发出（超时、网络断开）或 HTTP 状态码非 2xx → 直接 reject 并映射为用户友好文案
2. **业务层异常**：HTTP 200 但 `code !== 0` → reject，message 优先取后端返回值，缺失时用业务码映射表兜底
3. **请求超时**：`ECONNABORTED` → "请求超时"
4. **未知网络错误**：→ "网络异常，请检查网络连接"
